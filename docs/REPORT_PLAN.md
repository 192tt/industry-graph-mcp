# 产业洞察报告能力规划（v1）

## 外部做法摘要

| 来源类型 | 代表性做法 | 我们可借鉴 |
|----------|------------|------------|
| 咨询/行业研究（McKinsey 式、industry-research Skill） | 结论先行；概览→规模→产业链→竞争→PEST/SWOT→趋势风险；图表≥5 | 固定章节契约；执行摘要 + 产业链 + 竞争 + 风险 |
| 产业链深度模板（industry-deep-explainer） | TL;DR → 全景图 → 上中下游拆解 → 供需 → 代表企业 → 机会/风险 | Mermaid 产业链图；节点代表企业表 |
| 学术 KG+报告（Graphy、GenKD、VESA） | 从图数据出洞察；仪表盘多视图；LLM 按大纲写报告 | 从图库统计驱动图表；图谱可视化嵌入报告 |
| 商业查询/产业报告（艾瑞等） | 概览、产业图谱、竞争格局、案例、趋势 | 样本口径声明；图谱截图；头部案例 |

## 本产品报告定位

基于**本机知识图谱公开样本**的区域产业洞察（非付费库全量、非完整市场规模测算）。  
强调：**图文并茂**——统计图 + 产业链示意图 + **知识图谱截图/渲染图**。

## 交付格式

1. **Markdown 主报告**（可预览）：章节完整，内嵌相对路径图片  
2. **HTML 图文版**（浏览器打开更佳）：同结构，图片直接展示  
3. **assets/**：PNG 图表与图谱渲染图  

路径示例：`D:\industry-graph-mcp\reports\{scope}\{timestamp}_洞察报告\`

## 固定章节（契约）

0. 封面信息与样本口径  
1. 执行摘要（TL;DR，5–8 条）  
2. 样本与数据口径（企业数、关系数、来源构成）+ **统计图**  
3. 产业全景与结构（细分分布、区县分布若有）+ **柱状/饼图**  
4. 知识图谱视图 + **图谱渲染图/截图**  
5. 竞争与聚类观察（头部企业、关系类型）  
6. 代表企业速览表（Top-N）  
7. 政策与外部信号（若有检索素材）  
8. 机会、风险与下一步  
9. 附录：方法、来源、免责声明  

## 图从哪里来

| 图 | 生成方式 |
|----|----------|
| 细分产业分布、角色分布、关系类型 | matplotlib 出 PNG |
| 产业链示意 | Mermaid（MD/HTML） |
| 知识图谱 | networkx 抽样渲染 PNG；并复制/刷新 `graph_viewer.html` 供人工精看 |

## MCP 工具

- `generate_insight_report(scope, title, max_companies_in_table=30)`：一键出图文报告  
- 保留 `save_report_tool` 作自由文本落盘  

## 叙事原则

- 论断 → 图谱/统计证据 → 解读 → 局限  
- 凡无公开数据的市场规模数字，标注「样本内观察」或「未获取」
