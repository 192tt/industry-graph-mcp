# 请别人体验

产业图谱 MCP 是本机 stdio 服务，不绑定某一种聊天软件。Cursor、Claude Code、Claude Desktop、Codex、WorkBuddy 接的是同一条命令。数据写在对方自己的电脑上。

完整流程图见 [全流程.md](全流程.md) 第 7 节。下面是可直接转发的步骤。

## 准备

- Python 3.10 或 3.11（不要用 3.14）
- 能访问公网
- 下面任意一种客户端：Cursor、Claude Code、Claude Desktop、Codex、WorkBuddy

## 1. 安装（各客户端相同）

```powershell
git clone https://github.com/192tt/industry-graph-mcp.git
cd industry-graph-mcp
py -3.11 -m pip install -e .
py -3.11 -m industry_graph_mcp setup -y --backend sqlite
py -3.11 -c "import sys; print(sys.executable)"
```

最后一行是配置里要用的 `command`。没有 D 盘时，先设置再 setup：

```powershell
$env:INDUSTRY_GRAPH_MCP_HOME = "$env:USERPROFILE\industry-graph-mcp"
```

默认数据目录是 `D:\industry-graph-mcp`。

## 2. 接到客户端

`args` 都是 `-m industry_graph_mcp mcp`，环境变量都是 `INDUSTRY_GRAPH_MCP_HOME`。

| 客户端 | 怎么加 |
|---|---|
| Cursor | `%USERPROFILE%\.cursor\mcp.json` 的 `mcpServers`，然后 Reload |
| Claude Desktop | `%APPDATA%\Claude\claude_desktop_config.json` 的 `mcpServers`，然后重启 |
| Claude Code | `claude mcp add industry-graph-mcp --env INDUSTRY_GRAPH_MCP_HOME=D:\industry-graph-mcp -- py -3.11 -m industry_graph_mcp mcp` |
| Codex | `%USERPROFILE%\.codex\config.toml` 的 `[mcp_servers.industry-graph-mcp]` |
| WorkBuddy | 其 MCP 配置里填同一条 command / args / env，并放入 `SKILL.md` |

Cursor / Claude Desktop 的 JSON：

```json
{
  "mcpServers": {
    "industry-graph-mcp": {
      "command": "C:\\Path\\To\\python.exe",
      "args": ["-m", "industry_graph_mcp", "mcp"],
      "env": { "INDUSTRY_GRAPH_MCP_HOME": "D:\\industry-graph-mcp" }
    }
  }
}
```

Codex 的 TOML：

```toml
[mcp_servers.industry-graph-mcp]
command = "C:\\Path\\To\\python.exe"
args = ["-m", "industry_graph_mcp", "mcp"]

[mcp_servers.industry-graph-mcp.env]
INDUSTRY_GRAPH_MCP_HOME = "D:\\industry-graph-mcp"
```

ChatGPT 网页不能直接启动本机进程，见 `configs/chatgpt_tunnel.md`。

## 3. 对话里发这一句

> 调研杭州科技企业，企业尽量多，最后出政策解读和产业洞察报告。

## 4. 看结果

```text
D:\industry-graph-mcp\reports\杭州_科技\<时间>_insight\REPORT.md
```

同目录 `assets\graph_viewer.html` 是交互图谱。让模型调用 `ping`，版本应为 0.5.0。

看三件事：企业数增加、节点有细分和角色、报告含政策解读和产业样本图。

公开检索不是工商全量；名称推断不是官方分类；政策摘要要核对原文。
